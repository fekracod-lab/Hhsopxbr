================================================================================
          نظام مدار لإدارة المطاعم ونقاط البيع (Madar POS)
                         دليل وتعليمات التثبيت
================================================================================

أهلاً وسهلاً بك في معالج تثبيت نظام "مدار" المتكامل للمطاعم والكاشير والبيع المباشر.
تم تصميم هذا النظام ليعمل بأعلى معايير الاستقرار والسرعة والاعتمادية.

--------------------------------------------------------------------------------
1. متطلبات التشغيل الدنيا (System Requirements):
--------------------------------------------------------------------------------
- نظام التشغيل: Windows 10 أو Windows 11 (نواة 64-bit).
- المعالج: Intel Core i3 / AMD Ryzen 3 أو أعلى.
- الذاكرة العشوائية (RAM): 4 جيجابايت كحد أدنى (يوصى بـ 8 جيجابايت لتشغيل فائق السرعة).
- التخزين: مساحة فارغة 500 ميجابايت على القرص الصلب (SSD يفضل).
- الشاشة: دقة 1366x768 أو أعلى (يدعم الشاشات التي تعمل باللمس Touchscreen).

--------------------------------------------------------------------------------
2. توافق الأجهزة والملحقات (Hardware Compatibility):
--------------------------------------------------------------------------------
- طابعات الفواتير والإيصالات الحرارية (Thermal POS Printers):
  * مقاس 80 ملم (الأكثر شيوعاً) و 58 ملم.
  * منافذ التوصيل المدعومة: USB, LAN / Ethernet, Wi-Fi.
- أدراج النقود (Cash Drawers): توصيل مباشر عبر منفذ RJ11 في الطابعة الحرارية.
- قارئات الباركود والـ QR Code: تدعم منافذ USB والاتصال اللاسلكي.

--------------------------------------------------------------------------------
3. ميزات النظام التشغيلية:
--------------------------------------------------------------------------------
- مزامنة سحابية لحظية ومباشرة مع منصة وتطبيق مدار للمستخدمين.
- دعم العمل الكامل بدون إنترنت (Offline Mode) مع تخزين محلي مشفر ومؤمن.
- إدارة الورديات، المبيعات المباشرة (سفري / صالة / توصيل)، وتقارير الإغلاق.

يرجى الضغط على زر "التالي" لمتابعة خطوات التثبيت واختيار مسار التثبيت المطلوب.
