# دليل تثبيت وتشغيل نظام مدار للمطاعم على ويندوز
## Madar POS - Windows Enterprise Installation & Operations Guide

---

## 🌟 نظرة عامة
تم تصميم وبناء **نظام مدار لإدارة المطاعم ونقاط البيع (Madar POS)** ليعمل كمنظومة متكاملة وسريعة على بيئة **Microsoft Windows**، مع مراعاة أعلى معايير الاستقرار، ومزامنة السحابة المباشرة (Firebase)، ودعم العمل دون اتصال بالإنترنت (Offline Mode) عبر قاعدة بيانات محلية مشفرة.

---

## 💻 1. متطلبات التشغيل (System Requirements)

| المكون | الحد الأدنى (Minimum) | الموصى به (Recommended) |
| :--- | :--- | :--- |
| **نظام التشغيل** | Windows 10 (64-bit) Version 1809+ | Windows 11 (64-bit) أو Windows 10 Pro |
| **المعالج (CPU)** | Intel Core i3 (الجيل الخامس فما فوق) / AMD Ryzen 3 | Intel Core i5 / AMD Ryzen 5 فما فوق |
| **الذاكرة (RAM)** | 4 جيجابايت | 8 جيجابايت أو أعلى (لسلاسة فائقة) |
| **التخزين (Storage)** | 500 ميجابايت مساحة حرة | محرك أقراص سريع (NVMe / SATA SSD) |
| **الشاشة** | دقة 1366 × 768 | دقة 1920 × 1080 (تدعم اللمس Touchscreen) |
| **المنافذ** | 2 منفذ USB للطابعة والدرج | منافذ USB متعددة + منفذ إيثرنت LAN |

## 📦 2. طرق التثبيت والتوزيع (Distribution Options)

يوفر نظام مدار خيارين رئيسيين لتوزيع وتشغيل البرنامج على أجهزة الكاشير ونقاط البيع:

### الخيار الأول: برنامج التثبيت الرسمي الاحترافي (Setup Wizard `.exe`)
*الأفضل لتثبيت البرنامج بشكل دائم ورسمي في المطعم مثل البرامج العالمية.*
1. تشغيل ملف التثبيت: `Madar_POS_Setup_v1.0.0.exe`.
2. تظهر واجهة المعالج الترحيبية متضمنة شروط الاستخدام ومتطلبات النظام.
3. يتيح المعالج:
   - تحديد مسار التثبيت الافتراضي (`C:\Program Files\Madar POS`).
   - إنشاء اختصار رسمي على سطح المكتب (Desktop Shortcut) بأيقونة النظام.
   - إنشاء مجلد في قائمة ابدأ (Start Menu).
   - فحص وتثبيت مكتبات C++ Runtime تلقائياً إن لزم الأمر.
   - إضافة خيار تشغيل التطبيق فور الضغط على "إنهاء".
   - تسجيل النظام في "إضافة وإزالة البرامج" (Add/Remove Programs) لإلغاء التثبيت النظيف متى ما رغب المستخدم.

### الخيار الثاني: النسخة المحمولة الفورية (Portable Edition `.zip`)
*الأفضل للتشغيل المباشر من فلاش ميموري (USB) أو للتجربة السريعة دون الحاجة لصلاحيات مدير النظام (Administrator).*
- مسار المجلد: `rest_madar/dist/Madar_POS_v1.0.0_Portable`
- الأرشيف الجاهز: `rest_madar/dist/Madar_POS_v1.0.0_Portable.zip`
- للتشغيل الفوري: النقر المزدوج على `تشغيل_نظام_مدار.bat` أو `rest_madar.exe`.
- لإنشاء اختصار على سطح المكتب: النقر على `إنشاء_اختصار_سطح_المكتب.bat`.

## 🛠️ 3. كيفية بناء برنامج التثبيت (Inno Setup)

لإنتاج ملف `Madar_POS_Setup_v1.0.0.exe`:
1. تأكد من توفر برنامج **Inno Setup 6** المجاني على جهاز المطور:
   - التثبيت عبر PowerShell:
     ```powershell
     winget install JRSoftware.InnoSetup
     ```
   - أو التحميل اليدوي من الموقع الرسمي: [jrsoftware.org/isdl.php](https://jrsoftware.org/isdl.php)
2. تشغيل سكربت البناء المؤتمت:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\build_windows_setup.ps1
   ```
3. ستجد ملف الإعداد النهائي جاهزاً في:
   `rest_madar\dist\installer\Madar_POS_Setup_v1.0.0.exe`

## 🖨️ 4. إعداد الطابعات وملحقات الكاشير (Hardware Setup)

### أ. طابعات الإيصالات والفواتير الحرارية (Receipt Printers 80mm):
1. قم بربط الطابعة بجهاز الكمبيوتر عبر كابل USB أو الشبكة المحلية (Ethernet LAN).
2. قم بتثبيت تعريف الطابعة (Driver) المرفق من الشركة المصنعة (مثل Xprinter, Epson, Bixolon, Sunmi).
3. اضبط حجم الورق الافتراضي في خصائص الطابعة على `Receipt 80 x 297 mm` أو `80mm Roll`.
4. افتح نظام مدار للمطاعم وانتقل إلى:
   **الإعدادات ⚙️ ➔ الطابعات ➔ اختيار الطابعة الافتراضية للفواتير**.
5. اضغط على **"طباعة تجريبية"** للتأكد من خروج الإيصال بوضوح وقص الورق آلياً (Auto-Cutter).

### ب. درج النقود (Cash Drawer):
- يتم توصيل كابل درج النقود (RJ11 / كابل هاتف صغير) مباشرة في المنفذ المخصص خلف الطابعة الحرارية.
- عند كل عملية دفع نقدي أو عند فتح الوردية، يرسل النظام إشارة النبضة لفتح الدرج تلقائياً.

## 🌐 5. السحابة والعمل دون اتصال (Cloud & Offline Sync)

- **الاتصال السحابي**: يتزامن التطبيق بصورة مستمرة مع Firebase Cloud Firestore لمزامنة المبيعات، تحديث قوائم الطعام، واستقبال الطلبات من تطبيق الزبائن.
- **انقطاع الإنترنت**:
  - في حال انقطاع شبكة الإنترنت داخل المطعم، لا يتوقف العمل إطلاقاً!
  - يقوم النظام تلقائياً بالتحويل إلى قاعدة البيانات المحلية السريعة (SQLite Database).
  - يتم حفظ الفواتير، وحساب الإجماليات، وطباعة وصولات الكاشير والمطبخ كالمعتاد.
  - فور عودة الإنترنت، يقوم محرك المزامنة (`PosSyncService`) بترحيل كافة الفواتير والعمليات المعلقة للسحابة بأمان دون أي تكرار.

## ❓ 6. الأسئلة الشائعة وحل المشكلات (Troubleshooting)

### س 1: هل يتطلب النظام صلاحيات Administrator لتثبيته؟
- تم ضبط معالج التثبيت على وضع `PrivilegesRequired=lowest` لكي يمكن تثبيته لأي مستخدم عادي أو تثبيته لجميع المستخدمين بصلاحيات المدير بحسب الرغبة.

### س 2: ماذا لو ظهرت رسالة Windows Defender SmartScreen "Windows protected your PC"؟
- تظهر هذه الرسالة مع أي ملف `.exe` جديد يتم تجميعه محلياً قبل توقيعه بشهادة رقمية (Code Signing Certificate).
- الحل بسيط جداً: اضغط على **More info (مزيد من المعلومات)** ثم اضغط على **Run anyway (تشغيل على أي حال)**.

### س 3: أين تُحفظ البيانات المؤقتة وسجلات النظام؟
- تحفظ ملفات قاعدة البيانات المحلية في مسار بيانات التطبيق الآمن لكل مستخدم:
  `%APPDATA%\MadarPOS\` أو داخل مجلد التطبيق المخصص.
