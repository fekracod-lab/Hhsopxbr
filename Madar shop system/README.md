# نظام كاشير ونقاط بيع المتاجر والمحلات — منظومة مدار (Madar Shop POS System)

نظام كاشير ونقاط بيع متكامل ومتخصص للمتاجر، السوبرماركت، محلات الألبسة، الإلكترونيات، والمحلات التجارية، مرتبط سحابياً في الوقت الفعلي مع منظومة **مدار (دلال القائم)**.

---

## 🌟 أبرز مميزات النظام

### 1. مزامنة فورية مع تطبيق مدار الرئيسي
- عند إضافة أو تعديل أي منتج في هذا النظام، يرتفع فوراً إلى مجموعة المتجر في فايربيس: `stores/{storeId}/products`.
- يظهر المنتج في ثوانٍ معدودة داخل تطبيق مدار للزبائن ومستخدمي التطبيق.
- **ميزة التمييز الذهبي (Featured ⭐)**: إمكانية تمييز أي منتج بنقرة زر ليحصل على إطار ذهبي وشارة "مميز في مدار" في واجهة التطبيق الرئيسي.

### 2. نقطة بيع سريعة (POS) تدعم قارئ الباركود
- دعم مباشر لأجهزة قراءة الباركود الليزرية عبر USB ولوحة المفاتيح.
- سلة مشتريات تفاعلية مع إمكانية تعديل الكميات والخصومات لكل مادة أو للفاتورة كاملة.
- ميزة **تعليق واسترجاع الفواتير (Hold Carts)** لخدمة زبائن الطابور بسلاسة.
- نافذة دفع سريعة تدعم النقد، البطاقات، نقاط مدار، وزين كاش، مع فئات نقدية سريعة وحساب دقيق للمتبقي للزبون.

### 3. طباعة إيصالات حرارية قياسية (Thermal Receipt 80mm)
- طباعة إيصالات فورية بتصميم أنيق يدعم اللغة العربية مع شعار المتجر وبيانات الفاتورة والباركود.

### 4. استقبال طلبات تطبيق مدار الحية (Live Online Orders)
- مراقبة الطلبات الواردة من زبائن تطبيق مدار أونلاين في الوقت الفعلي.
- تنبيه فوري بالطلبات المعلقة وإمكانية تغيير الحالة (قبول، تجهيز، تسليم، إلغاء).

### 5. إدارة الورديات وجرد الصندوق والتقارير (Z-Report)
- فتح وردية برصيد افتتاحي.
- تسجيل المصروفات النثرية وسندات الصرف من الصندوق.
- إغلاق الوردية وحساب النقد الفعلي والعجز أو الفائض وطباعة تقرير Z اليومي.

### 6. العمل بدون إنترنت (Offline-First via SQLite)
- قاعدة بيانات SQLite محلية تسجل جميع المعاملات في أقل من 15ms لضمان عدم توقف الكاشير إطلاقاً.

### 7. استقلالية تامة عن لوحة تحكم التطبيق
- يعمل النظام كمنظومة كاشير مستقلة للمتجر ولا يمس إطلاقاً كود أو ملفات لوحة التحكم المركزية (`admin_web`).

## 🚀 طريقة التشغيل

### تشغيل على ويندوز (Windows Desktop):
انقر نقراً مزدوجاً على ملف:
```text
run_windows.bat
```
أو عبر الطرفية:
```bash
flutter run -d windows
```

### فحص الكود:
```bash
flutter analyze lib/
```
